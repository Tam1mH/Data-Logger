# Data-Logger
a device for collecting environmental data using multiple sensors, capable of connecting to the internet so that the data can be stored directly in a database or locally 

## Komponen 

### Input
- DHT 22
- DS18B20
- BH1750
- Soil Capacitive Moisture

### Process 
- RTC
- ESP32 Devkit V4

### Output
- SD Card Modul (For local Storage)
- MQTT
- Thingspeak
- Google Sheet (Database)

### Power Supply
- Baterai Lithium 18650
- TP4056
- MT3608
- Mini Panel Surya

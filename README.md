# Data-Logger
Data logger dibuat untuk mengumpulkan data lingkungan dengan beberapa sensor dan dapat terhubung ke internet agar datanya dapat langsung disimpan di database maupun lokal 

## Komponen 

### Input
- DHT 22
- DS18B20
- BH1750
- Soil Capacitive Moisture

### Process 
- RTC
- ESP32 Devkit V4

### Output
- SD Card Modul (Untuk storage lokal)
- MQTT
- Thingspeak
- Google Sheet (Dataabase)

### Power Supply
- Baterai Lithium 18650
- TP4056
- MT3608
- Mini Panel Surya
